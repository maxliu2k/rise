Run TinySOL with:  RISE_DATA_ROOT=$RISE_TINYSOL_ROOT

CROSS-DATASET (definitive shortcut test; 9 shared classes, 9-way masked):
  TinySOL model      -> Philharmonia audio : macro-F1 0.43  (from 0.99 within)
  Philharmonia model -> TinySOL audio      : macro-F1 0.37  (from 0.99 within)
  Both collapse -> within-dataset accuracy massively overstates real timbre generalization.
  TinySOL transfers marginally better (0.43 vs 0.37). Caveat: part of the drop is the fixable
  silence-structure mismatch between the datasets, not only recording-condition confound.
