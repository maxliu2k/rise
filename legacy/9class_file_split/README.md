# Legacy 9-class file-split artifacts

This directory archives outputs from the superseded 9-class, file-level-split
pipeline. They are retained for historical reference only and must not be used
as inputs to the current 12-class, pitch-group-split pipeline.

- `repository-artifacts/` contains the small manifests, statistics, model files,
  and evaluation results that were already tracked by Git.
- `local-data/` contains large generated feature arrays and related local files.
  It is intentionally ignored by Git and may not exist in every clone.

The active paths under `all-samples/` and `artifacts/` must be regenerated by
the repaired pipeline before training or evaluation.
